# ペナントモード

実データのリーグを元に「世界」（セーブデータ）を作り、GM として球団を受け持って、シミュレーションでシーズンを重ねるモードです。
世界は実データとは別に保たれ、実データの画面・集計・管理画面には現れません。入口はヘッダーの「ペナント」です。

## 1シーズンの流れ

1. **世界を作る**: 元にするリーグと、受け持つ球団を選びます（ログインが必要）。開幕前の日程が作られます。
2. **進める**: GM ホームの「1日進める」「次の自軍の試合まで進める」「1週間進める」で試合を消化します。進めるのは世界のオーナーだけです。
3. **シーズン終了**: 日程をすべて消化すると、GM ホームに「シーズンを締める」が出ます。
4. **締める**: オフの処理を済ませて翌年へ進みます（下の「オフの規則」）。締めた後はオフの結果の画面へ移ります。
5. 翌年の開幕前のホームには前年の最終順位とオフの結果へのリンクが出ます。もう一度「進める」で翌年のシーズンが始まります。

1つの世界で続けられるのは10シーズンまでです。最後のシーズンは締められず、GM ホームに理由が出ます。

## オフの規則

「シーズンを締める」は、1つの操作で次を順に行います（元に戻せません。途中で失敗したときは何も変わりません）。

| 順 | 内容 |
| --- | --- |
| 引退・退団 | 年齢・能力・出場機会で決まります。41歳は必ず引退します。外国人選手は「退団」と表示し、日本人より辞めやすくなります。入団2年以内の若手は辞めにくくなります |
| ドラフト | 各球団が2〜8人の新人を迎え、1球団34人ほどに戻します。外国人は登録枠の内側で、年に2人までです。新人の質は前年の順位に左右されません |
| 成長と衰え | 年齢と成長型（早熟・普通・晩成）、項目ごとの差で、翌年の能力が決まります。若いうちは伸び、30歳を過ぎると衰えます。走力が最も早く、選球眼が最も遅く衰えます |
| 水準の調整 | 全体の平均と散らばりを毎年同じ水準に戻します（能力の「50」は1軍の平均という定義を保つため）。順位は変わりません |
| 編成の後始末 | 引退した選手を含む手動の編成の区画は自動に戻し、締めた直後のメッセージで知らせます |
| 翌年の日程 | 翌年の日程を作ります |

引退した選手の在籍は締めた年で終わり、過去の成績・タイトル・能力は残ります。新人は翌年から加入します。

## オフの結果の画面

締めた後に出る「○年オフ」の画面です（GM ホームの「○年のオフの結果」からも開けます。誰でも読めます）。

- **自軍**: 引退・退団した選手、新人、残った選手の能力の変化（差の大きい順）
- **リーグ別の引退・退団と新人**: 画面上の選択欄でリーグを切り替えます
- **成長と衰えの大きかった選手**: 世界全体の上位10人ずつ

能力は S〜G の区分と1〜100の数値で示します。「総合」は野手が打撃、投手が抑える力の値です。
年齢は、引退・退団は締めた年、新人と残った選手は翌年の開幕時点です。

## 選手ページの能力の推移

ペナントの世界の選手ページには、能力のカードの下に年度ごとの能力が並びます（年度・年齢・球団・各項目・総合）。
引退した選手は、最後の年に「（最終年）」が付きます。

## 成績の見方

世界の球団の選手一覧と成績一覧は、既定では「今季」の成績です（「通算」に切り替えられます）。
締めた直後の開幕前は今季の成績がまだ無いため、GM ホームの順位表・主力・タイトルは前年の最終のものを出します。
