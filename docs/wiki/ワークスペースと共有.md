リーグ・チーム・選手・試合・ペナントの世界は、どれも **ワークスペース** に属します。ワークスペースは「1つの野球の記録帳」で、
URL の `/w/<key>/` の下がそのワークスペースの画面です（key は10文字の英小文字と数字）。このページは、ワークスペースの
**公開と非公開**と、**誰が何をできるか（役割と権限）** をまとめます。

> ワークスペースは、ログインした人がトップ（`/`）から作れます（[作成と設定](#作成と設定)）。持ち主は、ほかの人を招待のリンクで
> 編集者・チーム担当として迎え、役割を変え、外せます（[メンバーと招待](#メンバーと招待)）。要らなくなったワークスペースは、持ち主が
> [削除](#削除)の画面で消せます。ワークスペースの中身（リーグ・チーム・球場）は、持ち主・編集者がサイトの[登録画面](#登録画面)で
> 作れます（空のワークスペースから、ブラウザだけで試合の登録まで進められます）。作るときは既定で**見本のリーグ**（6チーム・約2週間ぶんの
> 試合）が入り、作った直後から順位表・成績・試合の結果を眺められます（[見本のリーグ](#見本のリーグ)）。

## 公開と非公開

| 公開範囲 | ログインしていない人 | ログインした、メンバーでない人 | メンバー（持ち主・編集者・チーム担当） |
| --- | --- | --- | --- |
| 公開 | 読める | 読める | 読める（役割に応じて書ける） |
| 非公開 | ログイン画面へ（ログインすると同じ URL に戻る） | 404（ワークスペースがあることも明かさない） | 読める（役割に応じて書ける） |

- 公開範囲は、持ち主がワークスペースの[設定](#作成と設定)で切り替えます（運営者は管理画面の **ワークスペース** の行でも切り替えられます）
- 公開のワークスペースでも、メンバーでない人は読むだけです。書き込みの導線（登録フォーム・編集ボタン・世界の作成フォーム）は出しません
- トップ（`/`）の「あなたのワークスペース」には、メンバーとして入っているものだけを出します（公開でも、入っていないものは出しません）

## 役割

役割はワークスペースごとに決まり、表の事実から毎回導きます（役割そのものは保存しません）。

| 役割 | 決まり方 | ヘッダーの表示 |
| --- | --- | --- |
| 持ち主 | ワークスペースの持ち主（1人） | 持ち主 |
| 編集者 | ワークスペースの「編集者」の行（招待の受諾・持ち主の役割の変更。運営者は管理画面でも足せる） | 編集者 |
| チーム担当 | そのワークスペースの実データのチームの「担当者」（`Team.managers`）に1つ以上入っている（招待の受諾・持ち主の役割の変更。運営者は管理画面でも） | チーム担当 |
| 閲覧 | 公開のワークスペースを見に来た、メンバーでない人（未ログインを含む） | 閲覧 |

1人が複数に当てはまるときは **持ち主 > 編集者 > チーム担当 > 閲覧** の順で上を取ります（持ち主が担当を兼ねていても持ち主）。
ほかのワークスペースのチームやペナントの世界の球団の担当になっていても、このワークスペースの担当にはなりません。
サイトの画面（招待の受諾・役割の変更）と運営者の管理画面のどちらから割り当てても、1人の役割は1つだけになるよう同じ規則
（`Workspace` 集約）で検査します（管理画面では W4 T6 から。持ち主が担当を兼ねるような重なりは、それより前に管理画面で付いた行だけです）。

## 権限

| 操作 | 持ち主・編集者 | チーム担当 | 閲覧（メンバーでない人） |
| --- | --- | --- | --- |
| 読む（すべての画面） | できる | できる | 公開ならできる |
| 選手の登録・編集・退団・主将・支配下登録・FA 宣言 | すべてのチーム | 担当のチームだけ | できない |
| 試合の登録・スコアブックの記録 | すべての試合 | 担当のチームが関わる試合だけ（どちらか一方でよい） | できない |
| リーグ・チーム・球場の登録・編集・削除（[登録画面](#登録画面)） | できる | できない（画面も 403。導線も出さない） | できない |
| ワークスペースの名前・公開範囲の変更（[設定](#作成と設定)） | 持ち主だけ（編集者はできない。画面も 403。導線も出さない） | できない | できない |
| メンバーの招待・役割の変更・除名（[メンバーと招待](#メンバーと招待)） | 持ち主だけ（編集者はできない。画面も 403。導線も出さない） | できない | できない |
| ワークスペースの削除（[削除](#削除)） | 持ち主だけ（編集者はできない。画面も 403） | できない | できない |
| ペナントの世界を作る | できる | できない | できない |
| 世界を進める・締める・編成・設定 | 世界を作った人で、**今も**持ち主か編集者である人だけ（持ち主・編集者でも、作った人でなければできない） | できない（自分が作った世界でも読むだけ） | できない |
| 世界の削除 | 世界を作った人（今も持ち主か編集者）と、ワークスペースの**持ち主**（ほかの人が作った世界も） | できない | できない |

- **世界の書き込みは「作った人で、今も持ち主か編集者」だけ**です。作った人をメンバーから外す・チーム担当に変えると、その人の世界は
  読むだけになります（世界の行は変えないので、編集者に戻せばまた書けます）。ワークスペースの持ち主は、ほかの人が作った世界も
  **削除だけ**できます（進める・締める・編成・設定は作った人のまま。世界が残っているとワークスペースを消せないため。[削除](#削除)）
- **管理ユーザー（`is_staff`）・superuser は、サイトでは何の権限も持ちません。** superuser は管理画面に入れるだけで、ワークスペースに書くには
  そのワークスペースのメンバーである必要があります。管理画面に入れるのは superuser だけです（`is_staff` の印だけでは入れません。
  ヘッダーの「管理画面」のリンクも superuser にだけ出ます）
- 押しても弾かれるだけの導線は出しません。ログインしていない人の書き込みはログイン画面へ、ログインしていて権限の無い人は 403 です
- ほかのワークスペースの id を混ぜた書き込み（ほかのワークスペースのチームを相手にした試合の登録など）は、「見つからない」（404）か
  フォームのエラー（スコアブックの保存は 400 の JSON）になり、何も保存されません

## 作成と設定

- **作成**: ログインした人は、トップ（`/`）のワークスペースの一覧の下のフォームから、名前と公開範囲を決めてワークスペースを
  作れます。公開範囲の既定は**非公開**です。「**見本のリーグを入れる**」（既定はオン）を残すと[見本のリーグ](#見本のリーグ)が入り、
  外すと空のワークスペースになります。作った人が持ち主になり、作ったワークスペースのダッシュボード（見本ありなら順位表・部門の首位・
  最新の試合の結果、空なら「まだチームが登録されていません」と[登録画面](#登録画面)への案内）へ移ります
- **持てる数の上限**: 1人が**持ち主として**持てるのは3つまでです（運営者が環境変数 `WORKSPACE_MAX_OWNED` で変えられます。
  [本番公開](本番公開)）。編集者・チーム担当として入っているワークスペースは数えません。上限に達すると、トップの作成フォームの代わりに
  案内だけを出します。上限を超える送信は、フォームのエラー（「ワークスペースは1人3つまで作れます。」）になり、何も作りません。
  運営者は管理画面から上限を超えて作れます
- **設定**（`/w/<key>/settings/`）: 持ち主だけが、ワークスペースの名前と公開範囲を変えられます。ヘッダーのワークスペースの名前の
  メニューの「ワークスペースの設定」から開きます（持ち主にだけ出ます）。編集者・チーム担当・部外者は 403、ログインしていなければ
  ログイン画面へ移ります（非公開のワークスペースの部外者は 404）。「メンバーと招待」「削除」は同じ画面のタブです
- **切り替え**: ログインしていれば、ワークスペースの中のヘッダーの名前がメニューになり、自分のワークスペース（トップの一覧と同じ）と
  トップへ移れます

### 見本のリーグ

作ってすぐに、このアプリで何ができるか（スコアブックから入れた打席から、順位・成績・タイトル・ボックススコアまで自動で集計されること）を
眺められるよう、作成のときに小さい見本のリーグを入れます（W5。#81）。

- **中身**: 1リーグ（「見本リーグ」。外国人枠と支配下選手の登録枠は NPB の既定）・球場6・チーム6（本拠地つき）・各25人（全員支配下）・
  36試合（1チーム12試合。開幕から約2週間）。名前はすべて架空です。試合はすべて今日より前の日付になる年に入ります
  （今年の見本の期間が終わっていなければ前年）。選手と試合は、ワークスペースの key から決まる乱数で作ります
- **既定はオン**です。作成フォームのチェックを外すと空のワークスペースになります。見本の欄は作成のときだけで、設定の画面には出しません
- **普通の実データ**です: 見本の選手・試合も、自分で登録したものと同じように編集・削除でき（スコアブックで試合を直すと順位も変わります）、
  分岐元にしてペナントの世界も作れます。「見本かどうか」は記録しません
- **見本だけを消す・後から入れる導線はありません。** 見本の要らなくなったワークスペースは、ワークスペースごと[削除](#削除)して作り直します
- 見本を入れるのはワークスペースの作成と同じひとまとまりの処理で、途中で失敗するとワークスペースも作りません（持てる数も減りません）。
  そのときは作成フォームにエラーを出すので、見本のリーグを外せば作れます
- 運営者が `SAMPLE_WORKSPACE_KEY` で指す「**見本のワークスペース**」（トップの未ログインの画面からリンクする既存のワークスペース。
  [本番公開](本番公開)）とは別物です。こちらは、作った人のワークスペースの中に入る「見本の**リーグ**」と呼び分けます

## メンバーと招待

`/w/<key>/members/`（ヘッダーの名前のメニューの「**メンバーと招待**」か、設定の画面のタブ）で、持ち主がメンバーを管理します。
**見るのも書くのも持ち主だけ**です（編集者・チーム担当・部外者は 403、未ログインはログイン画面へ、非公開のワークスペースの部外者は 404）。

- **メンバーの一覧**: 持ち主 → 編集者 → チーム担当の順（同じ役割は名前順）に、チーム担当には担当チームを添えて出します。
  持ち主の行には役割の変更と除名を出しません（持ち主はもともと全権を持ち、外せません。持ち主の譲渡は運営者が管理画面で行います）
- **役割の変更**: 編集者・チーム担当の行の「役割を変える・メンバーから外す」から、役割（**全体を編集**＝編集者 ⇔
  **担当チームを編集**＝チーム担当）と担当チームを選び直します。担当チームの付け替えも同じフォームです。担当チームの選択肢は
  このワークスペースのチームだけで、「担当チームを編集」ではチームを1つ以上選びます（無ければフォームのエラー）。
  「全体を編集」を選んだときは、担当チームのチェックは読みません
- **除名**: 「メンバーから外す」で編集者・チーム担当を外します（このワークスペースの担当チームもすべて外れます。ほかの
  ワークスペースでの役割はそのまま）。自分から抜ける画面はありません（持ち主に外してもらいます）
- **招待**: 役割（と、チーム担当なら担当チーム）を選んで「**招待のリンクを発行する**」と、`/invitations/<トークン>/` の形の
  リンクを発行します。メールは送りません。**リンクは発行した直後の画面に1回だけ表示されます**（保存しているのはトークンの
  ダイジェストだけなので、あとから表示し直せません。なくしたら取り消して発行し直します）。受け取る人にリンクを渡してください
  - 招待は**発行から7日間、1回だけ**使えます。受諾されると消えます。期限切れ・使用済み・取り消した・存在しないリンクは、
    どれも同じ「見つからない」（404）です
  - 未使用の招待は一覧（役割・担当チーム・発行と期限の日時）に出し、「取り消す」で消せます。期限切れの招待は一覧に出さず、
    次に発行するときにまとめて消します
- **招待を受け取る**（`/invitations/<トークン>/`。ワークスペースの外）: リンクを開くと、ワークスペースの名前と、なる役割
  （と担当チーム）が出ます。
  - ログインしていなければ「**ログインして受け取る**」「**新規登録して受け取る**」を出します。新規登録した後はログインの
    画面へ移り（自動ではログインしません）、ログインすると招待の画面に戻ります
  - 「**招待を受け取る**」を押すと、そのワークスペースのメンバーになり、ダッシュボードへ移ります
  - すでにメンバー（持ち主を含む）なら受け取るボタンを出さず、ワークスペースへの入口だけを出します（招待は使われずに残ります。
    役割を変えたいときは持ち主が変えます）
- 新規登録・ログインの画面は `next`（戻り先）を運びますが、このサイトの中の URL だけです（外のサイトの URL は捨てます）

## 削除

`/w/<key>/delete/`（設定の画面の「**削除**」のタブ）で、持ち主がワークスペースを消します。**見るのも消すのも持ち主だけ**です
（編集者・チーム担当・部外者は 403、未ログインはログイン画面へ、非公開のワークスペースの部外者は 404）。

- 確認の画面に、消えるもの（リーグ・チーム・選手・試合の数）を出します。メンバー・招待も一緒に消えます。**元に戻せません**
- 消すには、**ワークスペースの名前をそのまま入力**して「削除する」を押します（違えばフォームのエラーで、何も消しません）。
  消したらトップ（`/`）へ移ります
- **ペナントの世界が1つでも残っていると消せません。** 確認の画面には削除のボタンの代わりに、理由と残っている世界の一覧
  （名前・作った人）と、各世界の削除の画面への導線を出します。持ち主は、ほかの人が作った世界も消せます（[権限](#権限)）
- ほかのワークスペースの行がこのワークスペースのチーム・選手などを指していて外せないとき（運営者が管理画面で直接書いた
  ときだけ起きます）は、理由（「ほかのワークスペースの試合（id=…）がこのワークスペースのチームを指しているため削除できません。
  運営者に連絡してください。」など）を出して、何も消しません
- 在籍の記録が無い選手はどのワークスペースにも属さないので消えずに残ります。運営者向けの管理コマンド `workspace_delete` も
  同じ処理で、運営者の管理画面の「ワークスペース」の削除も同じサービスを通します（世界が残るワークスペースには削除のボタンが出ません。[本番公開](本番公開)）

## 登録画面

ヘッダーの「**登録**」（持ち主・編集者にだけ出ます）から、ワークスペースのリーグ・球場・チームを作り、直し、消します
（URL は `/w/<key>/setup/leagues/`・`/w/<key>/setup/stadiums/`・`/w/<key>/setup/teams/` とその下の編集・削除、並べ替えの保存の `/w/<key>/setup/leagues/reorder/`・`/w/<key>/setup/leagues/<id>/teams/reorder/`）。タブは作る順（リーグ・球場・チーム）に並びます。チームはリーグに属し、本拠地は球場から選ぶので、リーグ（と球場）を先に作ります。リーグが無いうちはチームの作成フォームを出さず、リーグのタブへ案内します。

- **見るのも書くのも持ち主・編集者だけ**です（画面がフォームだけなので、書けない人には見せません。中身はリーグ画面・チーム一覧などで誰でも読めます）。
  チーム担当・ログインした部外者は 403、未ログインはログイン画面へ、非公開のワークスペースの部外者は 404 です
- チームが1つも無いワークスペースのダッシュボードとチーム一覧には、持ち主・編集者にだけ登録画面への案内を出します
- **名前はワークスペースの中で一意**です（リーグ名・球場名・チーム名。チーム名はリーグが違っても重複できません。前後の空白は除きます）。同じ名前はフォームのエラーになります。
  ほかのワークスペースやペナントの世界に同じ名前があっても構いません。長さはリーグ名50文字・球場名100文字・チーム名100文字まで
- **表示順は一覧の行をドラッグして決めます**（2026-10-25 決定。編集画面に表示順の欄はありません）。リーグの一覧、チームの一覧ではリーグごとに
  行をつかんで動かし、「並び順を保存する」で確定します（動かすまでボタンは出ません。「元に戻す」で開いたときの並びに戻ります）。
  チームは同じリーグの中でだけ動かせます（リーグを変えるのは編集画面の所属リーグ）。保存は**チーム・リーグの id の並び**を送り、
  送った並びが今の行とちょうど合わないとき（ほかの人が同時に行を足した・消したなど）は何も書かずに理由を出します（画面を開き直して
  やり直します）。JavaScript が動かない環境では並べ替えの導線が出ないだけで、一覧はそのまま読めます
- 新しいリーグは表示順の末尾に、新しいチームはそのリーグの末尾に入ります。所属リーグを変えたチームも、移した先のリーグの末尾に入ります
- 外国人枠（1軍登録の計・投手・野手）と支配下選手の登録枠は、既定が NPB の値（計4人・投手3人・野手3人、70人）で、空欄にすると無制限です
- **消せるのは空の行だけ**です。消せない行には一覧に「削除」を出さず、削除の画面を開いても理由と「戻る」だけを出します
  （送信しても何も消えません）。
  - リーグ: チームが1つも無いとき（チームを先に消すか、ほかのリーグへ移します）
  - 球場: どのチームも本拠地にしていないとき。**ペナントの世界の球団の本拠地も数えます**
  - チーム: 選手の在籍の記録・主将の在任の記録・試合が1つも無いとき（誤って作ったチームの取り消しのための削除です。
    どれかがあると、消すと選手の経歴や試合の記録まで消えるため）。削除の確認には、一緒に外れる担当者の割り当ての数を出します
    （担当者のユーザーそのものは消えません）
- **チーム**は名前・所属リーグ・本拠地（空欄なら本拠地なし）を入れます。所属リーグと本拠地の選択肢は、このワークスペースの
  リーグと球場だけです
- **所属リーグを変えられるのは、そのチームの試合が1つも無いときだけ**です（2026-10-25 決定）。所属リーグは期間を持たず、順位表や
  タイトルは今の所属リーグで数えるので、試合のあるチームを移すと過去のシーズンの順位表まで移した先で数え直されてしまうためです。
  試合のあるチームの編集画面には所属リーグの欄を出さず、今のリーグと理由だけを出します（送信しても所属は変わりません）。
  また、**今の支配下選手が移す先のリーグの支配下選手の登録枠を超えるチームは移せません**（フォームのエラー。育成選手は数えません）
- **球場はワークスペースのペナントの世界と共有します。** 世界の球団が本拠地にしている球場を直すと、世界にも映ります
  （収容人数はペナントの観客数の上限です）。編集の画面はそのことを先に知らせます。リーグ・チームは世界を作るときに写すので、
  実データのリーグ・チームを直しても（チームの本拠地を外しても）世界には映りません（[ペナントモードの仕組み](ペナントモードの仕組み)）

細かい決まり（担当の割り当て方・試合の対戦カードを書き換えるとき）は [チームと選手の管理](チームと選手の管理#チーム担当者と書き込みの権限)、
画面ごとの境界は [画面の歩き方](画面の歩き方#閲覧と書き込みの境界)、実装の置き場所は [アーキテクチャ](アーキテクチャ) の「権限の置き場所」を見てください。
