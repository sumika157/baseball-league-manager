リーグ・チーム・選手・試合・ペナントの世界は、どれも **ワークスペース** に属します。ワークスペースは「1つの野球の記録帳」で、
URL の `/w/<key>/` の下がそのワークスペースの画面です（key は10文字の英小文字と数字）。このページは、ワークスペースの
**公開と非公開**と、**誰が何をできるか（役割と権限）** をまとめます。

> ワークスペースは、ログインした人がトップ（`/`）から作れます（[作成と設定](#作成と設定)）。メンバーの招待とワークスペースの
> 削除の画面は、まだありません（W4 で足します）。今は運営者が管理画面で編集者とチーム担当を割り当てます。ワークスペースの中身
> （リーグ・チーム・球場）は、持ち主・編集者がサイトの[登録画面](#登録画面)で作れます（空のワークスペースから、ブラウザだけで
> 試合の登録まで進められます）。

## 公開と非公開

| 公開範囲 | ログインしていない人 | ログインした、メンバーでない人 | メンバー（持ち主・編集者・チーム担当） |
| --- | --- | --- | --- |
| 公開 | 読める | 読める | 読める（役割に応じて書ける） |
| 非公開 | ログイン画面へ（ログインすると同じ URL に戻る） | 404（ワークスペースがあることも明かさない） | 読める（役割に応じて書ける） |

- 公開範囲は、持ち主がワークスペースの[設定](#作成と設定)で切り替えます（運営者は管理画面の **ワークスペース** の行でも切り替えられます）
- 公開のワークスペースでも、メンバーでない人は読むだけです。書き込みの導線（登録フォーム・編集ボタン・世界の作成フォーム）は出しません
- トップ（`/`）の「あなたのワークスペース」には、メンバーとして入っているものだけを出します（公開でも、入っていないものは出しません）

## 役割

役割はワークスペースごとに決まり、表の事実から毎回導きます（役割そのものは保存しません）。

| 役割 | 決まり方 | ヘッダーの表示 |
| --- | --- | --- |
| 持ち主 | ワークスペースの持ち主（1人） | 持ち主 |
| 編集者 | 管理画面のワークスペースの「編集者」の行 | 編集者 |
| チーム担当 | そのワークスペースの実データのチームの「担当者」（`Team.managers`）に1つ以上入っている | チーム担当 |
| 閲覧 | 公開のワークスペースを見に来た、メンバーでない人（未ログインを含む） | 閲覧 |

1人が複数に当てはまるときは **持ち主 > 編集者 > チーム担当 > 閲覧** の順で上を取ります（持ち主が担当を兼ねていても持ち主）。
ほかのワークスペースのチームやペナントの世界の球団の担当になっていても、このワークスペースの担当にはなりません。

## 権限

| 操作 | 持ち主・編集者 | チーム担当 | 閲覧（メンバーでない人） |
| --- | --- | --- | --- |
| 読む（すべての画面） | できる | できる | 公開ならできる |
| 選手の登録・編集・退団・主将・支配下登録・FA 宣言 | すべてのチーム | 担当のチームだけ | できない |
| 試合の登録・スコアブックの記録 | すべての試合 | 担当のチームが関わる試合だけ（どちらか一方でよい） | できない |
| リーグ・チーム・球場の登録・編集・削除（[登録画面](#登録画面)） | できる | できない（画面も 403。導線も出さない） | できない |
| ワークスペースの名前・公開範囲の変更（[設定](#作成と設定)） | 持ち主だけ（編集者はできない。画面も 403。導線も出さない） | できない | できない |
| ペナントの世界を作る | できる | できない | できない |
| 世界を進める・締める・編成・設定・削除 | 世界を作った人だけ（持ち主・編集者でも、作った人でなければできない） | ← | ← |

- **管理ユーザー（`is_staff`）・superuser は、サイトでは何の権限も持ちません。** 管理画面に入れるだけで、ワークスペースに書くには
  そのワークスペースのメンバーである必要があります（管理画面のリンクはヘッダーに出ます）
- 押しても弾かれるだけの導線は出しません。ログインしていない人の書き込みはログイン画面へ、ログインしていて権限の無い人は 403 です
- ほかのワークスペースの id を混ぜた書き込み（ほかのワークスペースのチームを相手にした試合の登録など）は、「見つからない」（404）か
  フォームのエラー（スコアブックの保存は 400 の JSON）になり、何も保存されません

## 作成と設定

- **作成**: ログインした人は、トップ（`/`）のワークスペースの一覧の下のフォームから、名前と公開範囲を決めて空のワークスペースを
  作れます。公開範囲の既定は**非公開**です。作った人が持ち主になり、作ったワークスペースのダッシュボード（「まだチームが登録されて
  いません」と[登録画面](#登録画面)への案内）へ移ります
- **持てる数の上限**: 1人が**持ち主として**持てるのは3つまでです（運営者が環境変数 `WORKSPACE_MAX_OWNED` で変えられます。
  [本番公開](本番公開)）。編集者・チーム担当として入っているワークスペースは数えません。上限に達すると、トップの作成フォームの代わりに
  案内だけを出します。上限を超える送信は、フォームのエラー（「ワークスペースは1人3つまで作れます。」）になり、何も作りません。
  運営者は管理画面から上限を超えて作れます
- **設定**（`/w/<key>/settings/`）: 持ち主だけが、ワークスペースの名前と公開範囲を変えられます。ヘッダーのワークスペースの名前の
  メニューの「ワークスペースの設定」から開きます（持ち主にだけ出ます）。編集者・チーム担当・部外者は 403、ログインしていなければ
  ログイン画面へ移ります（非公開のワークスペースの部外者は 404）。メンバーと削除の画面は、同じ画面のタブに足していきます
- **切り替え**: ログインしていれば、ワークスペースの中のヘッダーの名前がメニューになり、自分のワークスペース（トップの一覧と同じ）と
  トップへ移れます

## 登録画面

ヘッダーの「**登録**」（持ち主・編集者にだけ出ます）から、ワークスペースのリーグ・球場・チームを作り、直し、消します
（URL は `/w/<key>/setup/leagues/`・`/w/<key>/setup/stadiums/`・`/w/<key>/setup/teams/` とその下の編集・削除、並べ替えの保存の `/w/<key>/setup/leagues/reorder/`・`/w/<key>/setup/leagues/<id>/teams/reorder/`）。タブは作る順（リーグ・球場・チーム）に並びます。チームはリーグに属し、本拠地は球場から選ぶので、リーグ（と球場）を先に作ります。リーグが無いうちはチームの作成フォームを出さず、リーグのタブへ案内します。

- **見るのも書くのも持ち主・編集者だけ**です（画面がフォームだけなので、書けない人には見せません。中身はリーグ画面・チーム一覧などで誰でも読めます）。
  チーム担当・ログインした部外者は 403、未ログインはログイン画面へ、非公開のワークスペースの部外者は 404 です
- チームが1つも無いワークスペースのダッシュボードとチーム一覧には、持ち主・編集者にだけ登録画面への案内を出します
- **名前はワークスペースの中で一意**です（リーグ名・球場名・チーム名。チーム名はリーグが違っても重複できません。前後の空白は除きます）。同じ名前はフォームのエラーになります。
  ほかのワークスペースやペナントの世界に同じ名前があっても構いません。長さはリーグ名50文字・球場名100文字・チーム名100文字まで
- **表示順は一覧の行をドラッグして決めます**（2026-10-25 決定。編集画面に表示順の欄はありません）。リーグの一覧、チームの一覧ではリーグごとに
  行をつかんで動かし、「並び順を保存する」で確定します（動かすまでボタンは出ません。「元に戻す」で開いたときの並びに戻ります）。
  チームは同じリーグの中でだけ動かせます（リーグを変えるのは編集画面の所属リーグ）。保存は**チーム・リーグの id の並び**を送り、
  送った並びが今の行とちょうど合わないとき（ほかの人が同時に行を足した・消したなど）は何も書かずに理由を出します（画面を開き直して
  やり直します）。JavaScript が動かない環境では並べ替えの導線が出ないだけで、一覧はそのまま読めます
- 新しいリーグは表示順の末尾に、新しいチームはそのリーグの末尾に入ります。所属リーグを変えたチームも、移した先のリーグの末尾に入ります
- 外国人枠（1軍登録の計・投手・野手）と支配下選手の登録枠は、既定が NPB の値（計4人・投手3人・野手3人、70人）で、空欄にすると無制限です
- **消せるのは空の行だけ**です。消せない行には一覧に「削除」を出さず、削除の画面を開いても理由と「戻る」だけを出します
  （送信しても何も消えません）。
  - リーグ: チームが1つも無いとき（チームを先に消すか、ほかのリーグへ移します）
  - 球場: どのチームも本拠地にしていないとき。**ペナントの世界の球団の本拠地も数えます**
  - チーム: 選手の在籍の記録・主将の在任の記録・試合が1つも無いとき（誤って作ったチームの取り消しのための削除です。
    どれかがあると、消すと選手の経歴や試合の記録まで消えるため）。削除の確認には、一緒に外れる担当者の割り当ての数を出します
    （担当者のユーザーそのものは消えません）
- **チーム**は名前・所属リーグ・本拠地（空欄なら本拠地なし）を入れます。所属リーグと本拠地の選択肢は、このワークスペースの
  リーグと球場だけです
- **所属リーグを変えられるのは、そのチームの試合が1つも無いときだけ**です（2026-10-25 決定）。所属リーグは期間を持たず、順位表や
  タイトルは今の所属リーグで数えるので、試合のあるチームを移すと過去のシーズンの順位表まで移した先で数え直されてしまうためです。
  試合のあるチームの編集画面には所属リーグの欄を出さず、今のリーグと理由だけを出します（送信しても所属は変わりません）。
  また、**今の支配下選手が移す先のリーグの支配下選手の登録枠を超えるチームは移せません**（フォームのエラー。育成選手は数えません）
- **球場はワークスペースのペナントの世界と共有します。** 世界の球団が本拠地にしている球場を直すと、世界にも映ります
  （収容人数はペナントの観客数の上限です）。編集の画面はそのことを先に知らせます。リーグ・チームは世界を作るときに写すので、
  実データのリーグ・チームを直しても（チームの本拠地を外しても）世界には映りません（[ペナントモードの仕組み](ペナントモードの仕組み)）

細かい決まり（担当の割り当て方・試合の対戦カードを書き換えるとき）は [チームと選手の管理](チームと選手の管理#チーム担当者と書き込みの権限)、
画面ごとの境界は [画面の歩き方](画面の歩き方#閲覧と書き込みの境界)、実装の置き場所は [アーキテクチャ](アーキテクチャ) の「権限の置き場所」を見てください。
